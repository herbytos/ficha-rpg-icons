## 📖 Sobre o Projeto
Este projeto nasceu da necessidade de ter uma alternativa moderna e prática às fichas de papel para o sistema de RPG de super-heróis ICONS. O objetivo é criar uma experiência de usuário fluida, onde jogadores e mestres possam gerenciar personagens de forma rápida, com cálculos automáticos e uma interface intuitiva.

Chega de apagar e reescrever pontos de Determinação ou fazer contas de poder no meio da ação!

## ✨ Funcionalidades
[x] Criação de Personagem: Interface guiada para criar seu herói do zero.

[x] Cálculos Automáticos: Atributos como Energia são calculados automaticamente.

[x] Rolagem de Dados: Botões integrados para rolar dados de atributos e poderes diretamente na ficha.

[x] Gerenciamento de Poderes: Adicione e edite os poderes do seu personagem com facilidade.

[x] Controle de Pontos de Determinação: Gaste e recupere pontos com apenas um clique.

[x] Modo Noturno: Um tema escuro para sessões de jogo até tarde da noite.

[x] Exportar/Importar: Salve sua ficha como um arquivo (JSON).

[x] Design Responsivo: Acesse sua ficha no computador, tablet ou celular.
